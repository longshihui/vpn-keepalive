# vpn-keepalive

可配置多地址的 HTTP 保活工具。`npx` 直接运行，本地 Web 界面配置，配置保存到本地数据目录。

## 快速开始

```bash
npx vpn-keepalive
```

运行后自动用系统默认浏览器打开界面（端口由系统自动分配，地址以启动输出为准），在界面中添加保活地址，保存后立即生效。`Ctrl+C` 停止。

也可以全局安装后运行：

```bash
npm install -g vpn-keepalive
vpn-keepalive
```

要求 Node.js 20+，支持 macOS、Windows、Linux。命令行解析基于 commander，端口查找基于 get-port，其余仅使用 Node 原生能力。

## 命令行

```bash
vpn-keepalive [--port <端口>] [--host <地址>] [--data-dir <目录>]
```

运行保活引擎并启动 Web 界面，交互式终端下自动打开浏览器。

| 选项                | 默认值      | 说明                                                           |
| ------------------- | ----------- | -------------------------------------------------------------- |
| `--port <端口>`     | 自动查找    | Web 界面端口；未指定时由 get-port 查找空闲端口，被占用回退随机 |
| `--host <地址>`     | `127.0.0.1` | 监听地址；仅本机访问，无需鉴权                                 |
| `--data-dir <目录>` | 平台默认    | 覆盖数据根目录，用于隔离运行                                   |
| `--help`            |             | 查看帮助                                                       |
| `--version`         |             | 查看版本                                                       |

## Web 界面

页面自上而下分为两个区块：

- **运行状态**：当前状态（保活中 / 待机）、地址数量、运行时长、下次请求倒计时、最近请求结果（成功 / HTTP 错误 / 超时 / 网络错误，含命中的地址）、「立即保活」按钮（手动触发一次请求，不影响既有周期），以及控制台日志视图（最多 10 行，最新在前，按级别着色：成功绿色、失败红色、信息灰色）。
- **保活配置**：地址表格（添加 / 删除）、请求间隔（整数分钟）、请求超时，保存后立即生效。

## 配置

保活配置保存在 `config.json`（位置见「数据目录」，固定为操作系统约定目录，不可修改），首次运行自动创建；也可以在 Web 界面中编辑，保存后热生效，无需重启。

```json
{
  "urls": ["http://10.249.12.234"],
  "intervalMinutes": 1,
  "timeoutMs": 10000
}
```

| 字段              | 默认值  | 约束                                              |
| ----------------- | ------- | ------------------------------------------------- |
| `urls`            | `[]`    | 保活地址列表，每项为非空 HTTP/HTTPS URL，不可重复 |
| `intervalMinutes` | `1`     | 请求间隔，只允许不小于 1 的整数分钟（最大 35791） |
| `timeoutMs`       | `10000` | 请求超时，正整数毫秒，最大 2147483647             |

`urls` 可配置多个地址（如多个 VPN 网关），每次请求随机选取其一；列表为空时引擎待机，不发任何请求。旧版配置中的 `url`（活动地址）字段已废弃，读取时自动忽略。

## 数据目录

配置文件与日志固定存放在操作系统为用户应用约定的数据目录，路径不可修改，避免自定义位置导致的读写权限问题，以及下次启动找不到配置：

- macOS：`~/Library/Application Support/vpn-keepalive`
- Windows：`%LOCALAPPDATA%\vpn-keepalive`
- Linux：`$XDG_CONFIG_HOME/vpn-keepalive`（默认 `~/.config/vpn-keepalive`）

数据根目录内包含 `config.json`、`state.json`（最近状态）、`run.lock/`（实例锁）与 `logs/`。日志为 `keepalive.log`，最多保留最近 10 行，超出丢弃最旧；请求不保存响应正文。

`--data-dir` 仅用于隔离运行（如开发与测试），不影响默认约定目录。

## 行为细节

- 启动时在交互式终端（TTY）自动用系统默认浏览器打开界面；管道、CI 等非交互环境仅输出界面地址。
- 地址列表非空时启动即请求一次（随机选取目标），此后按整分钟间隔周期请求；在途请求未结束（含超时等待）时跳过当期，不重叠。
- 同一数据根目录只允许一个实例（PID 存活检查）；进程异常退出后残留的锁会自动恢复。
- 修改保活配置保存后：中止当前周期与在途请求，按新配置立即请求并重启周期。
- 「立即保活」手动触发一次请求，不影响既有周期；在途请求未结束时等待其完成并展示结果。
- Web 界面端口默认由系统自动分配，每次启动可能不同；也可用 `--port` 指定，被占用时自动改用随机端口。界面地址以启动输出为准。
- HTTP 成功不代表目标服务可用，也不延长服务端的绝对会话时限。
